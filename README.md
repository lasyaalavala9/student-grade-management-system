# Student Grade Management System

## About the Project

This is a simple Student Grade Management System that I developed using Core Java as a student project. The main purpose of this project is to manage student details and marks and calculate their grades easily.

Through this project, I got practical experience with Java programming, classes and objects, ArrayList, and file handling.

## Features

- Add student details and marks
- View all student records
- Search for a student using student ID
- Update student details and marks
- Delete a student record
- Calculate total marks and percentage
- Display grades and pass/fail results
- View class statistics and the topper
- Save student records in a text file

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- File Handling
- VS Code
- Git and GitHub

## Files in the Project

- `Main.java` – Contains the main method and menu.
- `Student.java` – Stores student details and calculates marks, percentage, and grade.
- `GradeManager.java` – Handles adding, viewing, searching, updating, and deleting student records.
- `FileManager.java` – Saves and loads student data from a file.
- `data/` – Stores the student records.

## How to Run the Project

**Step 1:** Install JDK on your computer.

**Step 2:** Download or clone this repository.

**Step 3:** Open the project folder in VS Code or Command Prompt.

**Step 4:** Compile the Java files.

```bash
javac Main.java Student.java GradeManager.java FileManager.java
```

**Step 5:** Run the program.

```bash
java Main
```
